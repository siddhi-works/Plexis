# Friction log

Problems hit while building Plexis as an Alexa+ add-on, in the order they came up. These are the hackathon's "developer feedback" notes. Each entry says what happened, what it cost, and what Plexis does about it.

## Platform access

1. **The MCP Toolkit is partner-only preview.** We could not run `alexa-ai configure`, `deploy` or the certification checks. Because of that, `addon.json` is written from the quickstart's published field limits, not generated by the CLI. A real Alexa+ device never exercised Plexis, so we built a simulated host (`simulator/`) that is a real MCP client.
2. **Latency numbers disagree.** The quickstart says round trips must be under 500 ms. The functional requirements say search results within 3 s (otherwise send an interim message). We designed for 500 ms on the server and stream progress notifications for anything longer. The simulator's latency tab draws the 500 ms line.
3. **The 401 behavior conflicts with the MCP spec.** The quickstart wants a 401 *without* `WWW-Authenticate` ("not supported yet"). MCP 2025-11-25 (RFC 9728 discovery) wants the header. Plexis supports both via `QED_ALEXA_COMPAT_401`: the header is on in dev and off in the container.
4. **Small inconsistencies in the authentication page.**
   - The metadata example lists `refresh_token`, but the token rules rule it out for `client_credentials`.
   - The scope is spelled `mcp:resource` in one place and `mcp:resources` in another.

   Plexis issues no refresh tokens and uses `mcp:resources`.
5. **Elicitation support depth isn't documented.** The client-lifecycle page says Alexa+ "tries to infer context first, then elicits", but doesn't say which form-schema types render. Plexis keeps every elicitation to a single enum or boolean, and falls back to a confirmation token when the host doesn't advertise elicitation.

## SDKs and protocol versions

6. **The SDKs disagree on major versions.**
   - The Python MCP SDK is 2.x: `FastMCP` was renamed `MCPServer`, and MCP Apps are in core.
   - Strands Agents pins `mcp<2.2`, so we run Python MCP 2.1.1.
   - The TypeScript SDK is still 1.x (1.32.1).

   All three speak protocol 2025-11-25, which is what Alexa+ uses, so they interoperate. It still took an hour of reading source to confirm.
7. **Logging was deprecated in 2026-07-28, but it is the only push channel in 2025-11-25.** Disruption alerts are sent as `notifications/message` plus `notifications/resources/updated`. We suppress the deprecation warning with a comment explaining why.
8. **Hooking the TypeScript transport for the protocol trace isn't obvious.** The SDK assigns `onmessage` and then calls `start()`. Wrapping `onmessage` with a property accessor silently broke the connection. Wrapping `start()` works.

## Solvers

9. **CP-SAT's default linearization couldn't prove optimality on trips of five or more nights.** It sat at a 10% gap until the time limit. `linearization_level = 2` proves optimality in about 60 ms on the same models.
10. **Z3 times out proving tight budget conflicts.** On pseudo-Boolean budget sums it timed out after 15 s with every tactic we tried. We added an independent arithmetic cost floor as the first cross-check tier: the cheapest option per slot, plus a min-cost distinct-restaurant assignment when "no repeats" is in the conflict. It is instant, and anyone can redo it with a calculator. Z3 remains the second tier.

## Windows and tooling

11. **Windows' asyncio proactor logs a traceback whenever a browser drops a connection.** It is harmless and filtered in `qed dev`.
12. **Ruff's autofix turned escaped bidirectional characters into literal ones** in a regex and a test. Bandit then flagged them (Trojan Source, B613). We restored the `\u` escapes and added a repo scan for invisible characters.
13. **Boto spent about 20 s hunting for credentials** before Bedrock calls failed without an AWS account. Plexis now checks for credentials once and falls back to the deterministic compiler in milliseconds.

## Later in the build

14. **Wikimedia blocks generic HTTP clients** (403, robot policy) until the User-Agent names the project and a contact URL. Overpass (OpenStreetMap) returned 502 "at capacity", so place research relies on Wikivoyage plus a curated list.
15. **Windows speech (SAPI) must be created and used on one thread.** Calling it from an asyncio worker thread hung silently after the first sentence. Plexis's voice now owns a dedicated thread.
16. **An always-open microphone answers the TV.** Background speech was transcribed and treated as requests. Press-to-talk (like a wake word) plus dropping Whisper segments it marks as no-speech fixed it.
17. **LangGraph joins need the list form of `add_edge`.** A node with several parallel parents must use `add_edge([a, b], c)` to wait for all of them.
18. **An audit found that "proven" was only as good as the rules.** Seats left, rental-car return and time zones were missing from the shared trip definition, so all three checkers agreed on plans that would fail. They are now built-in rules checked by all three.

## Not done because of access

- Bedrock (Nova via Strands) and Bedrock Guardrails are implemented and tested with stubs, but never called live.
- The AgentCore Runtime deployment (stateful MCP) is documented in `deploy/agentcore/` but has not been run.
